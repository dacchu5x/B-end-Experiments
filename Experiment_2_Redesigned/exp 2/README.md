# BOOKNEST — Experiment 2

A redesigned visual theme for the original Library Management / 3D Cupboard Configurator experiment.

## Run locally

1. Open a terminal in this `exp 2` folder.
2. Run `npm install` once.
3. Run `npm start`.
4. Open `http://localhost:3001` (or the port printed by the server).

The original JavaScript, Node/Express server, phone validation module, and JSON customer data files are retained. The redesign changes the presentation layer and visible branding; it does not replace the existing configurator/customer-management behavior.
